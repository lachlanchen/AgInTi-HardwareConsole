# AgInTi Hardware Console

**Файловый цифровой двойник и рабочая станция управления лабораторным оборудованием.**

![Интерактивный атлас выводов](../docs/assets/hardware-console-interactive-pins.png)

Приложение объединяет платы, выводы, CPU, память, датчики, прошивки, телеметрию и управляющие намерения в графическом интерфейсе и структурированных JSON-файлах. `runtime/hardwarefs/` доступен скриптам и агентам.

## Возможности

- Диспетчер оборудования для CPU, контекстов, RAM, Flash, NAND, QSPI и подключений.
- Полный атлас выводов с подсказками, фиксацией выбора, цветами риска, масштабированием и панорамированием.
- Визуализация AS7343, TSL2591 и двух INA219.
- Сборка, прошивка, последовательный порт и безопасное управление STM32/ESP32.

Портативная версия Windows доступна в [Releases](https://github.com/lachlanchen/AgInTi-HardwareConsole/releases). При запуске платы не прошиваются и лампы не включаются автоматически.
