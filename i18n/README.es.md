# AgInTi Hardware Console

**Un gemelo digital basado en archivos y banco de control para hardware de laboratorio.**

![Atlas interactivo de pines](../docs/assets/hardware-console-interactive-pins.png)

Integra placas, pines, CPU, almacenamiento, sensores, firmware, telemetría e intenciones de control en una interfaz visual y archivos JSON estructurados. `runtime/hardwarefs/` permite automatización mediante scripts y agentes.

## Funciones

- Administrador de hardware para CPU, contextos, RAM, Flash, NAND, QSPI y conexión.
- Atlas completo de pines con ayuda al pasar el ratón, selección, riesgos, zoom y desplazamiento.
- Visualización de AS7343, TSL2591 y dos INA219.
- Compilación, programación, serie y control seguro para STM32/ESP32.

Descarga la versión portátil de Windows desde [Releases](https://github.com/lachlanchen/AgInTi-HardwareConsole/releases). La aplicación no programa placas ni enciende lámparas automáticamente.
